# ATAG

The [Authoring Tool Accessibility Guidelines (ATAG)](https://www.w3.org/TR/ATAG20/) explain how to make [authoring tools](https://www.w3.org/TR/ATAG20/#def-Authoring-Tool) accessible, and how those tools help authors create accessible content. ATAG is a [W3C Web Accessibility Initiative (WAI)](https://www.w3.org/WAI/standards-guidelines/atag/) specification.

The documents below are the ones listed on WAI's [ATAG overview](https://www.w3.org/WAI/standards-guidelines/atag/). This page is a reference to them, not a replacement.

## Specifications and supporting documents

- [ATAG 2.0](https://www.w3.org/TR/ATAG20/): the current [W3C Recommendation](https://www.w3.org/standards/types/#x5-1-recommendation). It has two parts: **Part A**, make the authoring tool user interface accessible; **Part B**, support the production of accessible content.
- [Implementing ATAG 2.0](https://www.w3.org/TR/IMPLEMENTING-ATAG20/): an informative guide for developers and evaluators, explaining how to meet each success criterion.
- [ATAG at a Glance](https://www.w3.org/WAI/standards-guidelines/atag/glance/): a one-page summary of the principles and success criteria.
- [ATAG 2.0 in Chinese](https://www.w3.org/Translations/ATAG20-zh/) (无障碍创作工具指南): authorized translation for reference. The English version is normative.

## Tools and implementation resources

- [ATAG Report Tool](https://www.w3.org/WAI/atag/report-tool/): generates reports on how well a tool meets ATAG 2.0.
- [Authoring Tools List](https://www.w3.org/WAI/tools-list/authoring/): accessibility information about common authoring tools.

## Guidance for specific tool types

- [Guidelines to Make Your LMS Accessible](https://www.w3.org/WAI/standards-guidelines/atag/education/): applying ATAG to learning management systems.
- [Guidelines to Make Your No-Code Website Tool Accessible](https://www.w3.org/WAI/standards-guidelines/atag/no-code/): applying ATAG to no-code site builders.
- [Guidelines to Make Your Social Media Platform Accessible](https://www.w3.org/WAI/standards-guidelines/atag/social-media/): applying ATAG to social media platforms.

## Updates and the next version

ATAG 2.0 is maintained by the [ATAG Community Group](../atag-cg/README.md), as no [ATAG Working Group](../atag-wg/README.md) has been chartered yet. A [proposed ATAG WG charter](https://www.w3.org/2026/11/proposed-atag-wg-charter.html) went to Advisory Committee review in November 2026. If approved, the working group would maintain ATAG 2.0 and [Implementing ATAG 2.0](https://www.w3.org/TR/IMPLEMENTING-ATAG20/), and develop a next version of ATAG covering developments since 2015 such as generative AI and API-driven, headless, and web-based platforms. The [CG charter](https://w3c-cg.github.io/atag/ATAG_Charter.html) covers similar groundwork: a review of ATAG 2.0 for out-of-date references such as WCAG 2.2, and incubation of guidance for AI and LLM-based authoring tools.

No draft update to ATAG 2.0 is published yet. [ATAG WG](../atag-wg/README.md) tracks the proposed working group and its deliverables, [ATAG CG](../atag-cg/README.md) tracks what the CG is producing, and [CG contributions](../../cg-contributions/README.md) holds this workspace's research.
