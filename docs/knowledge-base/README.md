# Knowledge base

General-purpose information relevant for a wide range of tasks in this workspace. The ATAG, ATAG WG, ATAG CG, and WCAG pages are evergreen references to upstream sources, so they stay useful as the group's own work changes.

- [ATAG](atag/README.md): the Authoring Tool Accessibility Guidelines specification.
- [ATAG WG](atag-wg/README.md): the proposed W3C Working Group that would develop the next version of ATAG.
- [ATAG CG](atag-cg/README.md): resources from the ATAG Community Group.
- [WCAG](wcag.md): the Web Content Accessibility Guidelines, including WCAG 3.0 and its working group.
- [Authoring tools](authoring-tools.md): list of authoring tools discussed by the ATAG Community Group so far.

Research the workspace contributes to the group's deliverables lives in [CG contributions](../cg-contributions/README.md).
