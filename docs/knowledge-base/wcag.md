# WCAG

The [Web Content Accessibility Guidelines (WCAG)](https://www.w3.org/WAI/standards-guidelines/wcag/) define how to make web content accessible to people with disabilities. ATAG refers to WCAG throughout: an authoring tool is only fully accessible if the content it helps authors produce meets WCAG.

## Versions

- **[WCAG 2.2](https://www.w3.org/TR/WCAG22/)** is the current W3C Recommendation. It is backwards compatible with WCAG 2.0 and 2.1, which remain normative.
- **[Understanding WCAG 2.2](https://www.w3.org/WAI/WCAG22/Understanding/)** explains the intent of each success criterion, with [techniques](https://www.w3.org/WAI/WCAG22/Techniques/) for meeting them.
- **[WCAG 3.0](https://www.w3.org/TR/wcag-3.0/)** is a W3C Working Draft, and the next generation of the guidelines. It reworks WCAG 2's conformance model around outcomes and a bronze/silver/gold scoring approach, and adds guidance for non-web content.

### WCAG 3.0 resources

- [WCAG 3.0 Working Draft](https://www.w3.org/TR/wcag-3.0/): the specification, published frequently.
- [WCAG 3 development](https://www.w3.org/WAI/standards-guidelines/wcag/wcag3-intro/): WAI's introduction, covering goals, status, and current drafts.
- [WCAG 3 draft guidelines](https://w3c.github.io/wcag3/guidelines/): the editor's draft of each guideline, with outcomes and methods.

## Working group

WCAG is developed by the [Accessibility Guidelines Working Group (AGWG)](https://www.w3.org/groups/wg/ag/), which also maintains WCAG 2.x. The group works in public:

- [AGWG working group page](https://www.w3.org/groups/wg/ag/): participants, charter, meeting minutes, and participation instructions.
- [Issues](https://github.com/w3c/wcag/issues) and [WCAG 3 issues](https://github.com/w3c/wcag3/issues) on GitHub.
- [Mailing list archive](https://lists.w3.org/Archives/Public/public-agwg-comments/).

## Related to ATAG

- [ATAG](atag/README.md) requires authoring tools to support authors in producing content that conforms to WCAG.
- [ATAG WG](atag-wg/README.md) is planned to liaise with AGWG so ATAG stays consistent with WCAG 2 and WCAG 3, which its proposed charter names as a coordination commitment.
- [ATAG CG](atag-cg/README.md) liaises with AGWG on the same topic, and is mapping each WCAG 3 provision to a possible ATAG relationship: ATAG as a method towards a provision, a supplemental ATAG reference, informative content, or none. That mapping shapes what the next version of ATAG adopts (Wendy Reid, Miriam Fukushima, [13 November 2026](https://w3c-cg.github.io/atag/minutes/minutes_Nov13_2026)).
