# WCAG 3 provisions relevance

Every provision in the [WCAG 3](https://www.w3.org/TR/wcag3/) Editor's Draft, in guideline order, as listed in the [WCAG 3 guidelines](https://w3c.github.io/wcag3/guidelines/) on 14 November 2026. Each one is a candidate for the "Relationship to ATAG" classification described in [WCAG 3 provisions review](wcag-3-provisions-review.md).
