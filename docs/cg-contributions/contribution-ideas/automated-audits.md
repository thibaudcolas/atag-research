# Automated audits

Automated accessibility and web sustainability audits for AI-assisted authoring:

- [Time to rethink Shift Left accessibility with agentic AI](https://wagtail.org/blog/time-to-rethink-shift-left-accessibility-with-agentic-ai/): average accessibility scores up 5 points, but there is more work to do and it needs a complete rethink (Wagtail CMS blog).
- [kinti/a11y-toolkit](https://github.com/kinti/a11y-toolkit): accessibility layer for AI coding agents, with static and rendered WCAG 2.2 audits, contrast over images, and PDF/DOCX screening.
- [Community-Access/accessibility-agents](https://github.com/Community-Access/accessibility-agents): WCAG 2.2 AA accessibility review for AI coding tools, as agent skills, an edit gate, and scanners.
- [Web sustainability agents](https://thibaudcolas.github.io/web-sustainability-agents/): research and implementation of agentic web sustainability audits.
- [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo): SEO skill for Claude Code that covers agent readiness, including agentic browsing checks, WebMCP, and `llms.txt`.
